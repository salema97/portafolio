# Steven Lema Portfolio

## What it is
Bilingual (EN/ES) static portfolio for Steven Lema, Full-Stack Software Engineer. Primary goal: hireability (recruiters, clients) and project showcase.

## Audience
Technical hiring managers, founders, and collaborators evaluating backend/full-stack work.

## Voice
Direct, professional, confident. True red cinematic dark theme (not pink). No marketing fluff.

## Core flows
- Browse projects with filters
- Read experience timeline
- Contact via mailto form
- Download CV from header

## Constraints
- Astro 5 static site, deploy to salema.dev
- Accessibility: WCAG AA contrast, reduced motion, keyboard nav
- Mobile-first; fixed header must not hide hero badge

## Register
Brand (portfolio). Design is the product.
